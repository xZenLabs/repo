# Arcana II — Version 7.0

A major update introducing new features, a redesigned experience, performance improvements, and stability fixes.

## What's New

- **Library:** A new optional module that lets you add and read books about **Tarot, astrology, occultism, spirituality, and much more**, without leaving Arcana II.
- **Book Collections:** Organize your books using native KOReader collections, including smart collections.
- **Book Management:** Search for metadata and covers online, rate books, mark favorites, and filter your library.
- **Reading Integration:** Open books directly in KOReader and return to the Arcana II Library when finished.
- **Customizable Home Screen:** Organize modules, personalize shortcuts, and navigate between sections with swipe gestures.
- **Expanded Quick Settings:** More device shortcuts, with customizable visibility and order.
- **Lock Screen Clock:** A large clock displayed in the Super Maples font, updating every minute.
- **Simplified First-Time Experience:** A cleaner default layout, with additional features available when needed.
- **Translations:** Improved Portuguese, English, Spanish, and Chinese translations.

## Fixes & Improvements

- Improved Library performance, including faster navigation and optimized cover caching.
- Fixed disappearing book covers when switching between viewing modes.
- Fixed errors when opening the Library without a selected folder.
- Improved navigation, interface consistency, and e-ink screen refreshing.
- Fixed issues related to PIN entry, screen locking, and resuming after sleep.
- Improved notification handling and overall stability.
- Fixed factory reset behavior to restore first-time configuration defaults.
- Improved installer compatibility with previous Arcana II releases.
- Preserved existing user data and preferences during updates.

# Arcana II — 7.0 版本

本次重大更新带来了全新功能、焕新的界面体验、性能优化以及多项稳定性修复。

## 新增功能

- **书库：** 全新可选模块，无需离开 Arcana II，即可添加和阅读有关**塔罗牌、占星术、神秘学、灵性以及更多主题**的书籍。
- **书籍收藏集：** 支持使用 KOReader 原生收藏集管理书籍，包括智能收藏集。
- **书籍管理：** 支持在线搜索书籍元数据和封面、为书籍评分、添加收藏以及使用筛选功能整理书库。
- **阅读集成：** 可直接通过 KOReader 打开书籍，并在结束阅读后返回 Arcana II 书库。
- **可自定义主页：** 自由管理模块、设置快捷方式，并通过滑动手势在不同模块之间切换。
- **扩展快捷设置：** 新增更多设备快捷操作，支持自定义显示、隐藏及排列顺序。
- **锁屏时钟：** 使用 Super Maples 字体显示大号时钟，每分钟自动更新。
- **简化首次使用体验：** 默认界面更加简洁，其他功能可根据需要自行启用。
- **多语言翻译：** 优化了葡萄牙语、英语、西班牙语和简体中文翻译。

## 修复与改进

- 优化书库性能，加快页面导航速度并改进封面缓存机制。
- 修复切换显示模式时部分书籍封面消失的问题。
- 修复未选择书籍文件夹时打开书库出现的错误。
- 改进导航体验、界面一致性以及电子墨水屏刷新效果。
- 修复 PIN 码输入、屏幕锁定及设备休眠唤醒后的相关问题。
- 优化通知管理并提升整体稳定性。
- 修复恢复出厂设置后未正确还原首次使用默认配置的问题。
- 提升安装程序与旧版 Arcana II 的兼容性。
- 更新过程中保留现有个人数据和用户偏好设置。
