# 用于KOreader和月读的ADHD仿生阅读插件,支持中英文

# （肘击AI做的）

为 [KOReader](https://koreader.rocks/) 打造的 EPUB 仿生阅读插件：把每个词的前半部分加粗，引导视线快速掠过，让阅读更轻松。支持英文和中文，针对 Kindle 等墨水屏设备设计，并兼容[月读](https://github.com/AnkioTomas/moon)。

## 功能特点

- **一键开关**：对 EPUB 按书开启或关闭，也可以设为所有 EPUB 默认开启，还能在手势管理器里绑定"仿生阅读：开关"。
- **不改原书**：原文件不会被修改。插件把转换后的内容存成缓存副本，KOReader 仍然认为你在读原书，书名、阅读进度、阅读历史都保持不变。
- **英文和中文分别设置**：英文按词加粗；中文没有空格，按固定字数分组加粗。两套设置互相独立。
- **丰富的外观选项**：加粗强度、跳词间隔、词干长度、词尾亮度、6 种强调样式、6 种颜色（彩色屏幕）。
- **预设**：英文、中文各自可以保存多套设置，一点即用。
- **批注自动同步**：在原书里划的线、写的笔记、加的书签，打开仿生版就在；在仿生版里做的批注，几秒后自动同步回原书。新增、修改、删除都会同步，位置按文字内容换算并核对，不会错位。
- **备份与还原**：每天第一次打开书时自动备份一次，也可以随时手动备份（可自定义名称），只保留最近 3 份。还原只补回缺失的内容，也可以随时从备份里导入当前这本书的批注。
- **导出仿生 EPUB**：把本地书籍转换后导出成独立的 EPUB，拿到其他设备上也能用。
- **月读兼容**：装有月读时，会在月读的阅读面板里增加"仿生阅读"按钮，并支持月读在线书源的章节。没装月读也完全可用。（没有测试月读5.24后的版本）
- **中英文界面**：菜单语言可随时切换，默认跟随 KOReader 的界面语言。

## 兼容性

| 项目 | 说明 |
|---|---|
| 已验证设备 | Kindle 2024|
| 其他设备 | 理论上能运行 KOReader 的设备都可以使用，但**未经测试** |
| 支持格式 | 仅 EPUB。PDF、MOBI、AZW3 等格式不支持，可先用 Calibre 等工具转成 EPUB |
| 依赖 | 无需其他插件。月读为可选 |

## 安装

1. 在本仓库的 **Releases** 页面下载最新的 `bionic.koplugin-vX.Y.Z.zip`。请下载 Release 里上传的这个文件，**不要**下载页面上自动生成的 "Source code"。
2. 解压，得到 `bionic.koplugin` 文件夹。**文件夹名字不要修改**。
3. 用 USB 线连接 Kindle，把 `bionic.koplugin` 整个文件夹复制到 KOReader 的 `plugins` 目录。Kindle 上通常是 `/mnt/us/koreader/plugins/`。
4. 弹出设备，在 KOReader 中重启（或退出 KOReader 后重新进入）。
5. 打开任意 EPUB，在顶部菜单里找到"仿生阅读"。

## 快速上手

**菜单位置**（可能因 KOReader 版本略有差异）：

- 阅读时：顶部菜单 → 排版标签页 → 仿生阅读
- 文件管理器：顶部菜单 → 更多工具 → 仿生阅读

**开始使用：**

1. 打开一本 EPUB，勾选"本书启用仿生阅读"。第一次开启时需要转换整本书，大书在老设备上可能要等一会儿，之后会直接使用缓存。
2. 想让所有 EPUB 默认开启，勾选"所有 EPUB 书籍默认开启"。
3. 在"英文（拉丁字母）"和"中文（汉字）"里调整效果。改动会立刻应用到正在阅读的书。
4. 想快速开关，可以在 KOReader 的手势管理器里为某个手势绑定"仿生阅读：开关"。

## 设置说明

### 英文（拉丁字母）

英文、希腊文、西里尔文等使用空格分词的文字都按这里的设置处理。

| 设置项 | 范围 | 默认 | 说明 |
|---|---|---|---|
| 对英文文字启用仿生效果 | 开 / 关 | 关 | 需要手动开启 |
| 加粗强度 | 1 – 4 | 2 | 每个词加粗多少。1 最少，4 为整个词干 |
| 跳词间隔 | 0 – 4 | 0 | 两个被加粗的词之间跳过几个词。0 表示每个词都加粗 |
| 词干长度 | 30 – 100% | 70% | 较长单词中可被加粗部分的占比 |
| 词尾亮度 | 20 – 100% | 100% | 未加粗部分的亮度。100 表示不变暗，**墨水屏建议保持 100** |
| 强调样式 | 6 种 | 加粗 | 加粗、半粗、特粗、下划线、加粗 + 下划线、斜体。半粗和特粗取决于字体是否有对应字重 |
| 强调颜色 | 开 / 关 | 关 | 仅彩色屏幕有效 |
| 颜色 | 6 种 | 红色 | 红、蓝、绿、橙、紫、棕。颜色已调暗，适合彩色墨水屏 |

### 中文（汉字）

### 理论上日文、韩文也可用？

中文没有空格，无法识别词语，所以插件把文字**每 N 个字分成一组**，再对每组的前半部分加粗。这是一种固定字数的近似做法，不是真正的分词。

| 设置项 | 范围 | 默认 | 说明 |
|---|---|---|---|
| 对中文文字启用仿生效果 | 开 / 关 | 关 | 中文汉字没有空格，无法识别词语。设为N时，每N个字视为一个“词”。0表示不处理中文汉字。 |
| 强调比例 | 20 – 80% | 50% | 每组中被强调的比例。50% 表示前一半 |
| 跳词间隔 | 0 – 4 | 0 | 两个被强调的分组之间跳过几组 |
| 词尾亮度 | 20 – 100% | 100% | 每组中未强调部分的亮度 |
| 强调样式、强调颜色、颜色 | 同英文 | 同英文 | 与英文分开设置 |

### 通用选项

- **变暗参照的页面主题**：浅色页面（深色文字）或深色页面（浅色文字）。只在词尾亮度低于 100% 时有影响。
- **本书使用独立设置**：勾选后，这本书使用自己的一套设置，不影响其他书。取消勾选则回到全局设置。
- **清除转换缓存**：删除转换产生的缓存副本，释放空间。下次打开时会重新转换。
- **Language / 语言**：在菜单最底部，切换中文和英文界面。

## 预设

在"英文（拉丁字母）"和"中文（汉字）"设置页的最底部，各有一个"预设"入口。

- **将当前设置保存为预设…**：给当前设置起个名字保存。名字留空则自动命名为"预设 1"、"预设 2"。名字相同会更新原有预设。
- **默认设置**：内置的一项，恢复插件的默认值。
- **点击预设名称**：套用该预设。当前设置与某个预设完全一致时，它前面会打勾。
- **删除预设**：选择要删除的预设。

英文和中文的预设互相独立。**预设不会改变仿生效果的开关**：是否启用英文效果、是否启用中文效果，由你手动开关，再选择预设。中文的"分组大小"同时也是中文效果的开关，所以只有在中文效果已经开启时，套用预设才会修改它。

## 批注、同步、备份与还原

"批注"指高亮、笔记和书签。

### 原书与仿生版之间的同步

菜单：仿生阅读 → 批注同步

同一本书的原文和仿生版是两份不同的排版，EPUB 里批注的位置记在文字结构里，不能直接通用。插件会把每条批注的位置按"文字内容"换算到另一个版本，换算后还会核对划线的文字对不对，对不上就不写入，所以不会错位。

- **原书 → 仿生**：在原书里新增、修改或删除批注，打开仿生版时会自动带过来。如果这本书已经有仿生版的转换缓存，改动也会马上写进仿生版那一套；还没有转换过的书，等第一次用仿生版打开时再带过去。
- **仿生 → 原书**：在仿生版里新增、修改或删除批注，约 3 秒后自动同步到原书；关书时还会再检查一次。
- **同步的内容**：高亮、笔记、书签。新增、修改（笔记、颜色、样式、划线范围）和删除都会同步。
- **换仿生设置也不丢**：改了加粗强度等会改变文字结构的设置后，批注会通过原书带到新设置的版本里。

**这个菜单里有：**

- **在原书与仿生版之间同步高亮和笔记**：同步的总开关，默认开启。
- **立即同步本书**：先把当前的改动同步过去，再重新打开这本书，把另一个版本里的改动也带进来，并重试之前失败的条目。
- **未能同步的批注（n）**：见下文。只能在书里使用。
- **立即备份…**、**每天自动备份一次**、**从备份导入本书的批注**：见下文"备份"。

**同步失败怎么办：**极少数批注可能换算不了，例如那段文字在两个版本里对不上，或章节排版不规范。它们不会丢，会出现在"未能同步的批注（n）"里，同时弹出提示。点开其中一条，可以：

- **按文字搜索并导入**：在另一个版本里找这段文字，放上去。
- **放弃（不再同步这一条）**：以后不再尝试同步它。

也可以用"全部按文字搜索并导入"一次处理全部。

### 笔记是怎么保存的

仿生效果会改变文字结构，所以插件内部让**每一种文字结构拥有自己独立的一套批注**，再通过上面的同步，让这些套和原书保持一致（原书是中转站）：

- 开关仿生效果、改变加粗强度、跳词间隔、词干长度、强调样式、词尾是否变暗、中文分组参数，都会切换到另一套。
- 只改颜色、词尾亮度的具体数值、页面主题，不会切换。
- 其他几套批注不会丢失，换回对应设置时，会自动和原书对齐。

> 旧版本里原文和仿生版的批注是分开的，现在会自动同步。升级后第一次打开一本书时，插件会核对已有的批注是在哪个版本里做的，再放到正确的位置。

### 备份

菜单：仿生阅读 → 备份批注

- **立即备份…**：弹出命名框。填写名称，或留空使用日期时间作为名称。
- **每天自动备份**：每天第一次打开书时（在做任何同步之前）自动备份一次，名称为"自动备份 日期"。可以在"批注同步"菜单里关闭。如果当天打开时还没有任何批注，会隔几个小时再试。
- **只保留最近 3 份**：手动备份和自动备份合在一起，只保留最新的 3 份，更早的会自动删除。想长期保留某一份，请把 `bionic_backups` 里对应的文件夹复制到别处。
- **删除备份**：列出所有备份，点击某一项并确认后删除。也可以一次删除全部。
- 备份范围：阅读历史中的书、插件处理过的书，以及当前打开的书。月读在线书源的章节和转换缓存不在其中。
- 每个备份保存在 `koreader/bionic_backups/<日期时间>/`，包含三个文件：
  - `backup.lua`：完整数据，用于还原
  - `backup.txt`：可直接阅读的批注文本
  - `info.lua`：名称、时间等简要信息

### 还原

菜单：仿生阅读 → 备份批注 → 还原备份

- **只能在文件管理器里还原**（没有打开任何书时）。因为打开的书在关闭时会把内存里的批注写回磁盘，会盖掉还原的内容。
- 还原只会**补回书里缺失的**批注，**不会删除或修改**已有内容，所以重复还原也不会产生重复。
- 批注会回到它原来所属的那一套，不会错位。补回的批注会在下次打开这本书时同步到另一个版本。
- 已经找不到的书会被跳过，并在结果里提示。

两个小限制：

- 如果你在备份之后故意删掉了某条批注，还原会把它补回来。
- 补回的批注会按文档位置插入，但同一段落里夹着标题、图片等内容时，顺序可能有细微出入，只影响"下一条高亮"的跳转顺序，不会丢失数据。

### 在书里从备份导入本书的批注

菜单：仿生阅读 → 批注同步 → 从备份导入本书的批注

随时可用，不需要关书。只补上这本书还没有的批注，已有的不动。备份里属于另一个版本（原书，或当前这套仿生设置）的批注会先换算位置再放进来；属于其他仿生设置的批注无法换算，会被跳过，结果里会提示数量。导入后会自动同步到另一个版本。

## 导出仿生 EPUB

菜单：仿生阅读 → 导出 → 导出仿生 EPUB

把本地书籍转换后导出成独立的 EPUB 文件，可以拿到其他设备上阅读。

- 可选择是否在导出文件的书名后加上"(Bionic)"，避免和原书重名。
- 默认导出到 `documents/bionic_export`，也可以修改导出文件夹。
- 仅支持普通 EPUB，不支持月读在线书源章节。

## 与月读配合

- 没装月读：插件完全正常，与月读相关的文件和菜单项不会产生任何影响。
- 装了月读：阅读面板里会多一个"仿生阅读"按钮，并可设置"月读在线书源章节默认开启"。
- 月读在线书源的章节会被**原地改写**（原文备份为 `.html.bionic`）。在书里关闭仿生后，章节会在下次打开时逐章还原；卸载插件时会自动全部还原。
- 月读仍在快速迭代。月读升级后，如果面板里的按钮消失，或在线章节不再生效，请提交 Issue。

## 数据存放位置

以下路径都在 KOReader 的数据目录下（Kindle 上通常是 `/mnt/us/koreader/`）：

| 路径 | 内容 |
|---|---|
| `settings/bionic_reading.lua` | 插件的设置、预设和批注同步记录 |
| `bionic_cache/` | 转换后的缓存副本，可随时清除 |
| `bionic_backups/` | 备份（手动的和每天自动的，只保留最近 3 份） |
| `bionic_save/` | 卸载时才会创建，存放保留下来的笔记文本和备份 |
| `../documents/bionic_export/` | 默认的导出位置 |

## 更新

菜单 → 仿生阅读 → **检查更新**（需联网）。更新后重启 KOReader；旧版本保留为 `plugins/bionic.koplugin.old`，可手动回滚。

## 卸载

在**文件管理器**里（不要在书里）：仿生阅读 → 卸载仿生阅读…。会弹出三个选项：

- **取消**：什么都不做。
- **卸载**：书籍还原为原文，仿生效果下做的笔记保存为一个文本文件，放在 `koreader/bionic_save`。插件、缓存、设置和所有备份会被删除。
- **卸载并保留备份**：在上面的基础上，额外保留最新的一份备份，同样放在 `koreader/bionic_save`。如果以后要重新使用，把其中的备份文件夹复制回 `koreader/bionic_backups/` 即可。

`bionic_save` 文件夹只在卸载时创建，并且只在确实有内容要保存时才会出现。

## 常见问题

**看不到加粗效果？**
有些字体没有粗体字重。可以换一个带粗体的字体，或者把强调样式改成"下划线"。"半粗"和"特粗"是否有效，取决于字体是否有对应字重。

**菜单里"本书启用仿生阅读"是灰色的？**
当前打开的不是 EPUB。本插件只支持 EPUB。

**第一次开启很慢？**
第一次需要转换整本书，之后会直接使用缓存。大书在较老的设备上会更慢。

**改了设置后阅读位置有点偏？**
改变文字结构的设置会触发重新转换，插件会按百分比回到原来的位置，可能有轻微偏差。

**我的高亮不见了？**
先看"仿生阅读 → 批注同步 → 未能同步的批注"里有没有。批注按文字结构分套保存，并通过原书同步（见上文），把设置改回做批注时的状态也会自动对齐。也可以用"从备份导入本书的批注"或"还原备份"补回。

**在原书里划的线，仿生版里没出现？**
确认"批注同步"里的总开关已勾选，然后点"立即同步本书"。还是没有的话，看"未能同步的批注"，那里会列出没能换算的条目，可以按文字搜索并导入。

**缓存占用空间太多？**
菜单里"清除转换缓存"会显示占用大小，点击即可清除。

**中文效果看起来很奇怪？**
中文是按固定字数分组，不是真正的分词，所以加粗的位置不一定落在词语边界上。可以试试不同的分组大小和强调比例。

## 已知限制

- 仅支持 EPUB。
- 中文是固定字数分组，不是分词。
- 只在 Kindle 2024上验证过。
- 批注同步靠文字内容换算位置。极少数情况（文字在两个版本里对不上、章节排版不规范，例如在表格里直接放文字）会换算失败，进入"未能同步的批注"，可手动按文字搜索导入。
- 使用旧版排版 DOM 的书不参与同步，会自动跳过。
- 只有当前这套仿生设置会和原书实时同步；以前用过的其他设置，换回去时才会对齐。
- 插件用到了 KOReader 的一些内部接口，KOReader 大版本更新后可能需要适配。升级 KOReader 后建议先备份批注，再用一本不重要的书试一下
- 调整词尾亮度可能会导致翻页动画卡顿，如有此情况，改回默认值或关闭翻页动画即可。
- 没有测试月读5.24之后的版本
