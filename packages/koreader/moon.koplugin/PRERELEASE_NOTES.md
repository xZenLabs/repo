# #126 刷新诊断测试包

基于正式 v0.5.17，仅叠加翻页耗时日志与可选刷新触发源诊断。包内版本：`0.5.17-refresh-diag.20261114`。

**这是短期定位用的测试包，不是闪烁修复版，也不通过正式自动更新分发。** 不改变刷新周期、壁纸渲染、刷新参数或驱动波形。

完全退出 KOReader，解压附件，将 `book.koplugin` 覆盖到 `koreader/plugins/`，然后重启。无需删除其他插件或 `.moon`，不清理配置和阅读数据。

在「设置 → 维护 → 其它 → 刷新诊断」开启追踪，关闭并重新打开书后生效。同一本书、其余设置不变，分别关闭/开启阅读壁纸，重启后连续翻 5–10 页，再通过远程管理网页「下载日志」导出两份日志。

记录刷新触发代码位置与调用链、请求和合并后的类型、周期全刷晋升、驱动提交参数及 ioctl 错误。新增刷新诊断行不记录书名、正文或账号；驱动 `UPDATE_MODE_FULL` 不等于软件请求 flashing 全刷。

本包包含尚未提交的诊断改动；预发布标签只标记 v0.5.17 底包。**请下载 Assets 中的插件 ZIP，不要使用自动生成的 Source code ZIP/TAR。**

测试完成后可覆盖回正式 v0.5.17；若继续保留测试包，请关闭「刷新诊断」并重新打开书，避免长期详细追踪。
