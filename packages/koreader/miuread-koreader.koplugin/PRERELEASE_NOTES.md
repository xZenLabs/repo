# v6.3.0-beta.7 · 2026-10-29

- 统一阅读时长菜单语义：设置入口与开关分离，E-Ink 授权进入独立管理页，支持扫码、验证及取消授权。
- 为主页、阅读器、同步、下载、账号、扩展与维护菜单增加统一的黑白 SVG 图标映射；阅读器列表现在也可渲染图标。
- 智能模式 Web→E-Ink 切换等待现有 Worker 写入屏障的非阻塞确认，拒绝重叠计时；保留 Web 精确进度同步。
- 网络恢复可提前唤醒 E-Ink 队列；仅清除授权失败对应的重试时间，保留限流和 unknown 安全边界。
- 设置模式变更仅停止阅读时间服务，不再取消阅读进度相关异步任务。

# v6.3.0-beta.1 · 2026-10-29

- 评论获取改为真正非模态的小型底部进度条，显示已完成章节数与百分比，不再复用 EPUB 下载的大型进度弹窗；只有进度条本身绘制不透明白底，不使用全屏白色遮罩。
- 小进度条增加黑白本地图标与三个操作：「后台进行」（仅隐藏界面，继续下载）、「暂停 / 继续」（停止后续章节，手动继续）、「取消」（停止任务，保留已存评论）。
- 评论菜单按需显示「评论获取任务」入口，后台运行或暂停后可重新打开进度条；重新打开暂停任务不会自动恢复下载。
- 进度刷新按已完成章节/状态变化触发，关闭时延后重绘原阅读区域，避免白块和墨水屏残影；只刷新小浮窗区域，不全页绘制白色幕布。
- 保留单章隔离 Worker、缓存、失败记录以及已验证的阅读时间上报与进度同步协议；增加新的发布 UI 保护测试。
