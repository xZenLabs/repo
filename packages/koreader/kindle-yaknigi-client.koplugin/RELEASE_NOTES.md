# v0.9.11 · 2026-11-14

Добавили:
- Теперь в приложении доступны книги, которые вы загрузили самостоятельно в «Яндекс Книги». Также можно загружать свои прямо с устройства.
- В настройках теперь можно настраивать доступные шрифты. Каждый шрифт показан своим начертанием, лишние можно отключить.
- Приложение можно установить как плагин с ограниченным функционалом для KOReader на PocketBook, Linux или Android.

Исправили:
- Позиция с устройства не доходила до телефона, если устройство не засыпало. Теперь во время чтения она уходит раз в минуту.
- Синхронизация стала немного точнее.
- На некоторых устройствах не появлялась экранная клавиатура, теперь появляется.
- Обновления ставятся сами, без переустановки вручную.
- Мелкие баги.

Изменили:
- На главном экране больше нет кнопки «Синхронизировать», она убрана в системную шторку (свайп вниз), а также происходит автоматически.
