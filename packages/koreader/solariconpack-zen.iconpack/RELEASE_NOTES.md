# v1.0.0 · 2026-10-07

Standalone Solar icon packs for Zen UI and ZenOS, in Colour and Mono.

- `zen-solar-colour.zip`: soft pastel fills for colour e-ink screens.
- `zen-solar-mono.zip`: bolder outlines for black-and-white e-ink screens.

Each pack contains 160 original SVG icons and 40 filename aliases for Zen's Navbar, quick actions, and supported lookup actions. The source artwork is preserved. Five lookup actions without Solar equivalents use Zen UI and KOReader's bundled icons.

Copy a ZIP into `koreader/icons/zen/`, enable **Custom icons**, select the pack under **Custom icon pack**, and restart KOReader. Zen automatically extracts valid pack ZIPs.

Based on the Solar Icon Set by 480 Design, adapted by pxlflux, and packaged by xZenLabs. Icons are licensed under CC BY 4.0; attribution is included in each ZIP.

Validation: SVG parsing, Zen metadata and archive layout, ZIP limits and integrity, source-artwork preservation, and deterministic rebuilds passed.
