# v1.9.10 · 2026-11-19

阿页的阁楼（ko-paper-sprite）KOReader 插件 / 月读扩展 v1.9.10

安装：解压 paper-sprite.koplugin-版本号.zip，把 paper-sprite.koplugin 目录复制到 KOReader 的 plugins/ 下并重启。
作为月读扩展：同一个插件即可；月读首页「添加组件」里会出现「阿页」「阿页的阁楼」「阿页的明信片」「纪念物柜」。

纯离线。代码、文案与美术均为原创（MIT）。

- 修复：读书墙对月读已读改为打开阁楼或读书墙时按已读名册指纹对账后同步。空的一次导入不再永久跳过后来的已读，只打过旧版一次性标记的存档也会补漏；同一轮既有迟到旧书又有更新的书、或条数和最大时间不变但已读集合被替换时也会补上。查询或写入失败不前推对账指纹，可重试。只收录有阅读时间的书，沿用月读自己的完成时间，不用同步时刻冒充。历史补导和后来在月读里标记 / 跳到结尾落库的已读不发灵感；仍只给合格翻页读完的书奖励，且先收翻页账本再补月读，避免重复奖励。进读书墙会先同步。月读分章和衍生版按全书身份判断，不再把中间章当成整本读完；身份暂时对不上时宁可等下次同步，不回退到当前文档页数。旧墙上的文件哈希书签，只在能对上月读登记路径时与新的月读身份视为同一本，不凭书名合并，也不擅自删旧记录。
