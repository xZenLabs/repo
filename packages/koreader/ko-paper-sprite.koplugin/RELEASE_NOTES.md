# v1.9.0 · 2026-11-14

阿页的阁楼（ko-paper-sprite）KOReader 插件 / 月读扩展 v1.9.0

安装：解压 paper-sprite.koplugin-版本号.zip，把 paper-sprite.koplugin 目录复制到 KOReader 的 plugins/ 下并重启。
作为月读扩展：同一个插件即可；月读首页「添加组件」里会出现「阿页」「阿页的阁楼」「阿页的明信片」「纪念物柜」。

纯离线。代码、文案与美术均为原创（MIT）。

- 插件只入库一套彩色 PNG。运行时按设备显色：黑白墨水屏收成 3 级灰（`#000 #AAA #FFF`），彩色墨水屏只做轻微色域适配（仍明显是彩色），液晶接近原图。
- 合成、显色和打开界面增加了计时与更快的取色路径，减少重复计算。
- 收藏册支持明信片、列表和明信片墙三种视图，会记住上次选择；列表可点进详情，分享入口仍在。
- 分享改为先保存彩色 PNG（不跟当前屏幕的灰度或彩色墨水量化），并保留通过月读生成二维码分享。
- 图片改用区域 ui 刷新：进页、首次出现和每隔 5 次换图再做一次区域 full，同一拍多张图合并成一次刷新，减少整页闪黑。
- 已知限制：黑白机部分画面的横纹本版未处理。彩色分享尚未在真机完整点测；彩色墨水屏机型本轮未同步升级到本版，请更新后留意刷新和分享表现。
