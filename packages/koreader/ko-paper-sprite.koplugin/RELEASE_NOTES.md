# v1.5.0 · 2026-11-01

阿页的阁楼（ko-paper-sprite）KOReader 插件 / 月读扩展 v1.5.0

安装：解压 paper-sprite.koplugin-版本号.zip，把 paper-sprite.koplugin 目录复制到 KOReader 的 plugins/ 下并重启。
作为月读扩展：同一个插件即可；月读首页「添加组件」里会出现「阿页」「阿页的阁楼」「阿页的明信片」「纪念物柜」。

纯离线。代码、文案与美术均为原创（MIT）。

- 阅读计数：离开这一页时停满 10 秒、并且只跨 1–3 页，才记一次。连翻和进度条大跳不再计入灵感。
- 读完一本书：阁楼日志写一句带书名的告别。有划线时，读书墙贴上你自己划的那句（最多 42 字）。
- 锁屏：最近一张明信片可以当作月读组合壁纸的背景，铺满竖屏，地点、短句、署名和日期压在画面底部。在锁屏设置的「背景」里选「阿页的明信片」。需要月读已支持第三方锁屏背景。只看明信片时，主体选「无」。
- 阁楼：下滑可以关闭，方向跟随月读弹窗的开关（默认下滑，可改成上滑或关掉）。子页上滑下去也是关掉整间阁楼；标题栏左侧仍返回上一级。返回键同样关掉整间阁楼。

# v1.4.0 · 2026-10-31

阿页的阁楼（ko-paper-sprite）KOReader 插件 / 月读扩展 v1.4.0

安装：解压 paper-sprite.koplugin-版本号.zip，把 paper-sprite.koplugin 目录复制到 KOReader 的 plugins/ 下并重启。
作为月读扩展：同一个插件即可；月读首页「添加组件」里会出现「阿页」「阿页的阁楼」「阿页的明信片」「纪念物柜」。

纯离线。代码、文案与美术均为原创（MIT）。

- 依赖月读：没装月读时打开阁楼只弹提示；删掉原生界面兜底，界面一律用月读主题组件。阁楼改用月读底栏（阁楼 / 收藏 / 动态）切换：行囊 / 小铺 / 委托放在阁楼首页，动态页自带翻页。来客在家时，首页状态卡换成客人并可直接「招待」。

- AI 预取：今日小纸条改为一次预取一批（按时段入池，用时直接取，请求数大减）；来客一到就预取招待反应和在家描写；另外预取明信片句子（按地点入池）、旅途事件改写、委托托词，用时直接取，没有 AI 仍用本地文案。
- 设置「在顶部菜单显示」（月读设置 → 游戏 → 阿页的阁楼）：控制 KOReader 顶部菜单里的「阿页」页签，默认开。
- AI 文案跟随月读的「AI 回答语言」设置。
- 阅读联动：读完一本书（末页附近）变成「读书墙」书签并奖励灵感；书的类型（推理 / 诗 / 科幻 / 历史等）会让下一趟更爱去对应地点，48 小时内有效。
- 阿页成长：按出门 / 收信 / 读书 / 待客攒经验，分 5 阶。
- 旅途事件：8 种（躲雨、旅伴、捡到东西、老朋友、彩虹、奇遇等），影响时长、多寄一张、特产加倍、灵感或道具。
- 访客互动：在家时可「招待」访客送特产，交情 3 / 5 / 8 有回礼（心愿地点、道具、灵感）；访客偶尔点名要某件特产。
- 委托：每天 3 条、每周 1 条，完成后手动领灵感。
- 成就：远行 / 集信 / 特产 / 足迹 / 来客 / 读书 / 天气成册等，自动发灵感。
- 特产稀有度：稀有 / 少见 / 常见（按 id 固定）。
- 阁楼入口按用途分页：第 2 页「做事」（收拾行囊 / 小铺 / 委托，状态是阿页的成长），第 3 页「收藏」（明信片墙 / 特产柜 / 剪贴簿 / 来客簿 / 读书墙 / 成就）。
- 存档新增 `stats` / `quests` / `achieved` / `bonds` / `bookmarks` / `seen_souvenirs`，旧档自动补默认值（版本号仍为 4）。
