# v1.9.12 · 2026-11-27

阿页的阁楼（ko-paper-sprite）KOReader 插件 / 月读扩展 v1.9.12

安装：解压 paper-sprite.koplugin-版本号.zip，把 paper-sprite.koplugin 目录复制到 KOReader 的 plugins/ 下并重启。
作为月读扩展：同一个插件即可；月读首页「添加组件」里会出现「阿页」「阿页的阁楼」「阿页的明信片」「纪念物柜」。

纯离线。代码、文案与美术均为原创（MIT）。

- 修复：装了月读 0.8.x 后点「检查更新」报错 `module 'http.mirror' not found`，阿页没法自更新。月读 0.8 把镜像调度并进了 `http.github`，现在优先用它，旧版月读仍走 `http.mirror`。
- 诊断：存档事务开启 / 提交失败时把 SQLite 原始错误写进日志，不再只有一句 transaction failed。

- 优化：阁楼打开时不再按最多 60 秒轮询刷新。只在下一件旅行 / 来客等真实事件到期时调度；画面与文案没变就不重建界面。休眠时停掉计时器且不重绘，唤醒或再次打开再按当前时钟一次性补算，不重复发奖。被其他界面挡住或关闭后取消无意义重绘。倒计时不再每分钟改数字，在交互、事件或唤醒时刷新到正确文案。
- 修复：阁楼被弹窗挡住时到点的事件（明信片寄到、阿页回家）在弹窗关掉后不刷新，要等下一件事或手动点一下；现在弹窗关掉几秒内补画。
- 优化（小内存 Kindle）：翻页不再每页都查月读书库和算哈希。不算数的翻页（停留不到 10 秒、跳页）什么都不查；同一本书的身份只查一次，之后只读进度。伴读翻页时不再读档结算两遍。
- 优化：月读首页的阁楼 / 明信片 / 纪念物柜组件重绘时先比对数据，没变就不重建控件。
- 优化：锁屏整屏明信片合成不再先画一张两倍多宽的整幅再裁，竖屏瞬时内存少一大块，画面不变。伴读姿势原图用完即释放，不再常驻。
- 修复：阿页出门时点「惦记这里」只提示「阿页还在路上」，惦记不上；现在路上也能惦记，留给下一趟。取消按钮写明「不退灵感」。
- 优化：离开久了再打开书，阅读页不再把攒下的明信片、出门、回家、来客、成就一件件接连弹出来；只弹最要紧的一件（在家的客人 > 最新一张明信片 > 回家 > 出门 > 成就），关掉就算都看过，其余到阁楼里看。
- 优化：墨水屏刷新和月读一致，不再闪黑。之前打开阁楼、切到明信片 / 阁楼画面、关掉阁楼、连续换图每 5 次、阅读页伴读每翻 5 页，都会对图片区域补一次闪黑的 full，画面占大半屏时看起来像整屏全刷；现在都只用不闪的局部刷新，残影交给 KOReader 自己的全刷设置。
- 优化：自更新成功后删除旧版备份目录（约 90MB）；移除 27 个误入库的 `.part` 残留图片。

# v1.9.10 · 2026-11-19

阿页的阁楼（ko-paper-sprite）KOReader 插件 / 月读扩展 v1.9.10

安装：解压 paper-sprite.koplugin-版本号.zip，把 paper-sprite.koplugin 目录复制到 KOReader 的 plugins/ 下并重启。
作为月读扩展：同一个插件即可；月读首页「添加组件」里会出现「阿页」「阿页的阁楼」「阿页的明信片」「纪念物柜」。

纯离线。代码、文案与美术均为原创（MIT）。

- 修复：读书墙对月读已读改为打开阁楼或读书墙时按已读名册指纹对账后同步。空的一次导入不再永久跳过后来的已读，只打过旧版一次性标记的存档也会补漏；同一轮既有迟到旧书又有更新的书、或条数和最大时间不变但已读集合被替换时也会补上。查询或写入失败不前推对账指纹，可重试。只收录有阅读时间的书，沿用月读自己的完成时间，不用同步时刻冒充。历史补导和后来在月读里标记 / 跳到结尾落库的已读不发灵感；仍只给合格翻页读完的书奖励，且先收翻页账本再补月读，避免重复奖励。进读书墙会先同步。月读分章和衍生版按全书身份判断，不再把中间章当成整本读完；身份暂时对不上时宁可等下次同步，不回退到当前文档页数。旧墙上的文件哈希书签，只在能对上月读登记路径时与新的月读身份视为同一本，不凭书名合并，也不擅自删旧记录。
