# v1.2.0 · 2026-10-21

阿页的阁楼（ko-paper-sprite）KOReader 插件 / 月读扩展 v1.2.0

安装：解压 paper-sprite.koplugin-版本号.zip，把 paper-sprite.koplugin 目录复制到 KOReader 的 plugins/ 下并重启。
作为月读扩展：同一个插件即可；月读首页「添加组件」里会出现「阿页」「阿页的阁楼」「阿页的明信片」「纪念物柜」。

纯离线。代码、文案与美术均为原创（MIT）。

- 修复：阁楼翻页时底部页数在 3/5、3/7 之间来回跳（「最近」每页条数只往小收，不再回弹）。
- 修复：随机数在 LuaJIT 下精度溢出，约 1.6 万步就循环；改用 Park–Miller 乘同余。旧存档的种子照常可用，但之后抽到的结果与旧版不同。
- 天气：明信片的天气按出片时的季节和钟点加权（冬天多落纸屑、春天多花瓣、夜里多星夜、清晨多日出、傍晚多黄昏）。
- 节日：公历节日离线可用；农历节日和节气取自节日接口（`api.ankio.net/myrl`，一天一次，失败静默），月读里直接复用首页时钟的缓存。节日当天阁楼会提一句，明信片一半概率换成节日短句，访客更爱来（40% → 70%）。设置项 `festival_online = false` 可关闭联网。
- AI：请求失败（含超时）后允许再试一次；提示词带上节日和最近寄过的句子，减少雷同。
- 文案：地点、天气、节日各补一批短句，新增四季短句、按钟点的「今日小记」、出门纸条与日志变体（全部本地、离线可用，含 English / 繁體中文）。
- 节日素材：12 张节日小物（春节红包、灯笼、月饼等），节日当天出现在阁楼里，也用于节日短句的明信片。
- AI：新增两种触发——整趟旅行在界面关着时走完，下次打开后补写明信片句子和特产小注；阁楼每个时段一张「今日小纸条」（无 AI 时用本地池）。出门纸条也可由 AI 写。请求在途标记带超时，界面中途关掉不会卡死。
- 阅读：只把相邻翻页计入灵感，改字号、旋转、进度条跳转不再算。

# v1.1.0 · 2026-10-18

阿页的阁楼（ko-paper-sprite）KOReader 插件 / 月读扩展 v1.1.0

安装：解压 paper-sprite.koplugin-版本号.zip，把 paper-sprite.koplugin 目录复制到 KOReader 的 plugins/ 下并重启。
作为月读扩展：同一个插件即可；月读首页「添加组件」里会出现「阿页」「阿页的阁楼」「阿页的明信片」「纪念物柜」。

纯离线。代码、文案与美术均为原创（MIT）。

- 修复：阿页出门时阁楼不再出现阿页和访客；重绘秋 / 春 / 夏三张出门阁楼图。
- 多语言：界面与数据文案走 `papersprite.l10n`，提供 English / 繁體中文。
- 自更新：月读设置「系统」里新增「阿页的阁楼」页，可检查并安装 GitHub Release 新版，首页组件出现后每天最多自动检查一次。
- 工程：版本号改由 `papersprite/version.lua` 打包注入；打包脚本 `tools/package.sh`；测试入口改为 `spec/run.lua`；发布包名改为 `paper-sprite.koplugin-<版本>.zip`。
