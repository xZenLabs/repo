# v0.1.0 · 2026-11-20

First release.

While you drag to select text, a copy of the line you're selecting floats just above your finger, so you can see what you're highlighting. When you lift your finger, a compact popup appears above the selection instead of on top of it. You choose which actions it shows and in what order.

**To install:** download `fingertips.koplugin.zip` below, unzip it, and copy the `fingertips.koplugin` folder into KOReader's `plugins` folder (on a Kobo, `.adds/koreader/plugins/`). Then restart KOReader.

Tested on a Kobo Clara BW running KOReader 2026.07.02, with EPUB books. See the README for details.

<hr>

This is an early version, so if anything doesn't work smoothly for you, please [let me know](https://github.com/ironicsans/fingertips.koplugin/issues).
