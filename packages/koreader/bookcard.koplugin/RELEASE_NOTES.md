# v1.5.11

### Changed

The highlighted quote no longer repeats the one shown last time (when the book has more than one highlight), so it now changes on every card. Previously a plain random pick could return the same quote several times in a row, especially with only 2 highlights.

# v1.5.10

### Changed
The highlighted quote can now take up to 1–5 lines (default: 2) via the new **Card elements → Highlighted quote** submenu.
