# v1.6.0 · 2026-10-08

### Added
- New "Stats per row (centered cover only)" setting (Advanced Settings → Layout) that controls how many statistics appear side by side in the centered-cover layout's grid. Range is 1–5, default 2 (the previous fixed behavior).
- The setting is greyed out unless the "Cover centered, statistics grid below" layout is selected.

# v1.5.11 · 2026-10-01

### Changed

The highlighted quote no longer repeats the one shown last time (when the book has more than one highlight), so it now changes on every card. Previously a plain random pick could return the same quote several times in a row, especially with only 2 highlights.

# v1.5.10 · 2026-10-01
