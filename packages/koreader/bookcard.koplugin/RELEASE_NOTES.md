# v1.5.1

**Added**
- Image export now also runs shortly after a book is opened, not only on the timer, on close and on suspend. This keeps the exported card in sync with the book you just opened. It can be turned off under Advanced Settings > Image export > "Also save when opening a book" (on by default).
- New "Image format" option under Advanced Settings > Image export: choose PNG (default), JPG or BMP. Switching format rewrites the image immediately and removes the old-format file of the same name, including in the extra shared folder.

# v1.5.0

**New**

- New "Centered" layout option (Advanced Settings > Layout): the cover sits on its own, centered, with title/author/series below it and the statistics laid out in a 2-column grid underneath.

**Changed**
- "Grouped" is now the default text background grouping mode.
