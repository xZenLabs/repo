# v2.0.0 · 2026-10-04

##  Configure a folder with a gesture

The folder settings window can now be opened straight from a gesture:

**Menu →  Settings → Taps and gestures → Gesture manager** — pick a gesture, then choose **File browser → Folder memory: configure this folder**.

<img width="458" height="300" alt="filememory-300" src="https://github.com/user-attachments/assets/88348a86-ff33-4940-bbd8-86b930531dd0" />



##  Installation

1. Download `foldermemory.koplugin.zip`
2. Extract it into `koreader/plugins/`
3. Restart KOReader
