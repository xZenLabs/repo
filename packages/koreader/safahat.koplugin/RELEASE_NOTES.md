# V1.1.0

1- Back button everywhere — every screen (Home, Categories, book list, Search, Download folder, book detail) now has a ‹ Back control. Under the hood, opening a new screen no longer closes the one you came from — it stays stacked underneath, so Back just reveals it again instead of needing any complex history-tracking, going all the way back up to Home.
2- Default download folder is now /mnt/us/documents/ — the Kindle's own documents folder, so downloaded EPUBs show up in the stock Kindle library too, not just inside KOReader. (If you'd already set a custom folder before, that setting is preserved — this only changes the default for a fresh install.) I also moved the debug .txt dumps out to KOReader's own data folder so they don't clutter your documents directory alongside real books.
