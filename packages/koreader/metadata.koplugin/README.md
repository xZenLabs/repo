# metadata.koplugin

An online book metadata search plugin for KOReader.

> [!WARNING]
> This plugin writes KOReader custom metadata for local use. It does not rewrite the book file itself or update a Calibre library database.

> [!NOTE]
> This plugin has only been tested on Kindle Paperwhite (11th Generation).

## Features

- Search Douban Books, Google Books, Open Library, Bangumi, and AniList; preview and apply metadata and covers locally.

- File actions: `Search metadata`.

- Menu: `Search` -> `Metadata`. Configure sources, cover application, cover width, and detail font size. Long-press Google Books to set its [API key](https://developers.google.com/books/docs/v1/using).
