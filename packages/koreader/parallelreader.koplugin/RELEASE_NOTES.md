# v1.1 · 2026-11-25

### InkAway Integration

- Integrated [InkAway](https://github.com/EmirErtorer/ink-away.koplugin/tree/main/) as the annotation engine for Parallel Reader.
- Annotations are managed using InkAway's own storage system.

**Compatibility note:** Parallel Reader's InkAway integration was developed and tested with **InkAway 4.5.3**. Compatibility with other InkAway versions is not guaranteed, and the integration may stop working if InkAway's internal APIs or interfaces change.

### Performance Improvements
- Improved resource cleanup and memory management.
- Reviewed refresh handling and background activity to minimize unnecessary CPU and battery usage.
