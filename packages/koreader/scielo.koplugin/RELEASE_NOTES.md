# v0.1.0

First release.

- Search www.scielo.br articles via Crossref (SciELO DOI prefix 10.1590)
- Open by URL, DOI or SciELO article code
- Article metadata preview and PDF download with open-after-download
- Dispatcher action "SciELO search" for gestures and hotkeys
- ZenOS: detected as a launchable plugin menu (Launcher / Controls / Navbar)
- ZenPM: release ZIP installs as scielo.koplugin/ in the KOReader plugins directory
