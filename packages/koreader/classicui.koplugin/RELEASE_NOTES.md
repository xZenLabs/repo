# v0.7.5 · 2026-11-04

# 墨页 · ClassicUI 0.7.5

本版新增Voyage电池健康、书库封面缓存、自定义每页数量和收藏夹排列，补齐Wi-Fi状态，并整理书库设置分类。

## 新功能怎么用

### Voyage电池健康

进入「设置 → 设备与系统 → 电池健康」，查看容量保持率、电量、充电状态、循环次数、温度和电压。点击「刷新」重新读取。

容量保持率是**电量计报告的估算**，默认参考Voyage原装电池1320 mAh；更换过电池时，可在「记录与诊断 → 参考容量」按电池标签修改。缺失或异常读数会提示数据不足，高于参考值会提示核对。

「记录电池数据」默认关闭；开启后，KOReader清醒运行期间每10分钟及充电、休眠、唤醒时采样，休眠不主动唤醒。保留最近512条采样和90个日期摘要。「导出电池诊断」保存到KOReader的settings/einkfrontend-battery-diagnostic.json，不含序列号、账号或书籍信息。该功能按Voyage电量计接口适配，其他机型不会显示虚构健康度。

### 书库封面缓存

缓存自动生效。首次浏览未缓存的页面时，先显示书名和占位图，再逐本补齐封面；返回看过的页面或重新进入书库时复用缩略图。已有的有效CoverBrowser封面会优先复用，无需另装SimpleUI。

内存缩略图每实例最多4 MiB，磁盘共享最多32 MiB/512项。需要重建时，进入「设置 → 书库与文件 → 缓存与清理 → 清理书库封面缓存」。这只清理本模块缩略图，保留书籍、阅读记录和原生CoverBrowser数据库。

连续翻页位置先保存在内存，停止操作2秒后合并保存；离开页面、打开书籍、关闭或休眠时也保存。异常断电可能丢失尚未保存的最后少量翻页位置。

### 每页显示数量

书库右上角三个点 →「书库布局」；或「设置 → 书库与文件 → 显示与排列 → 书库布局」。设置封面列数、行数和列表每页数量，填0恢复自动。

页面会显示当前屏幕实际可容纳的书籍数量。横竖屏空间不足时会自动减少实际数量，保留原偏好，避免书名和底部按钮被挤出屏幕。

### 排列收藏夹

收藏页右上角三个点 →「排列收藏夹」，点一个收藏夹并输入目标位置，填1移到最前。返回收藏页，选择「排序：自定义」使用该顺序。新建、重命名、隐藏及成员管理仍在「管理收藏」中。

顺序与KOReader原生收藏共用，保留默认标志、文件夹规则、成员及夹内书籍顺序。本版调整的是收藏夹的先后顺序。

### Wi-Fi与刷新

下拉菜单的Wi-Fi圆形按钮在开关开启时变深色。电量左侧的Wi-Fi标识在已连接时为黑色、开启但未连接时较浅，关闭时隐藏；点击按钮使用KOReader原生开关与连接流程。无线连接状态不保证互联网可用。

书库切换分类、翻页和布局变化时请求整屏刷新。单张封面绘制失败时显示占位图，继续绘制其他书籍与底部导航。手动刷新使用下拉菜单的「全屏刷新」。

## 设置分类

「设置 → 书库与文件」按用途分为：传书与书库、显示与排列、收藏管理、缓存与清理；当前设备可用的原生项目收进文件与浏览。书库三个点已移除「书库设置」和「刷新页面」。设置搜索与离线指南同步新路径。

旧文件夹分类导入仍可在「设置 → 书库与文件 → 收藏管理 → 文件夹转为收藏」使用，同名增量补入，原书位置不变。

## 安装与验证

适配**KOReader v2026.07.1 / v2026.07.2**。下载ClassicUI_0.7.5_install.zip，完全退出KOReader，备份原插件与设置，将包内einkfrontend.koplugin覆盖到koreader/plugins/，保留目录名称后重启。源码包用于查看与开发，无需同时安装。
