# v1.3.0 · 2026-10-02

Bookshelf: if your Home tab is pinned to a fixed folder (or turned off), unlocking now opens the private folder on the shelf, showing every private book.

New read-only __SINDLE API so other plugins can tell whether the private library is open (reveals nothing while locked).

# v1.2.0 · 2026-10-02

Works with the Bookshelf plugin: unlocking shows the private library on the shelf; Home, power and "Lock now" lock it; nothing private shows while locked, even after a restart.
- New "Lock now" gesture / quick-menu action.
- The Privacy menu is always available inside private books.
- Wording: "code" is now "passcode".

# v1.1.0 · 2026-10-01

The decoy book is now created automatically on first run (with its cover), so installing from Storefront (an addon for Koreader) works out of the box. Download SINdle-v1.1.zip below, or install from Storefront by searching SINdle.

# v1.0.0 · 2026-10-01

First release. Download SINdle-v1.0.zip below, unzip, drag the koreader folder onto your e-reader, copy the decoy book into your library, and restart KOReader.

Full instructions are in the README.
