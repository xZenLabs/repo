# v3.9.5

> 本版为修复版，相对 v3.9.3 共修复 5 个问题。建议所有 v3.9.3 用户升级。

## 修复

### 1. 休眠壁纸左下角二维码 / Logo 会消失

此前第一次生成壁纸时二维码正常，之后重新生成就可能消失或变成花屏。

原因是绘制图片时复用了已解码的图片缓存，但传给了会「用完即释放」的图片组件，缓存里的图被提前释放，下一次再取出绘制时读到的是已释放的内存。现已改为不释放该缓存，二维码与 Logo 可稳定显示。

### 2. 进入「设置 → 手势」或「配置文件」闪退

之前注册墨痕统计入口时用错了调用方式，导致一个无效条目被写进 KOReader 的操作列表。之后只要打开「手势设置」或「配置文件」，KOReader 遍历该列表就会直接闪退。

现已改为正确调用，并补上了事件处理，绑定的手势可以正常调出墨痕统计面板。

### 3. Top 书单的「标注」「笔记」恒为 0

之前是按书名去阅读历史里查每本书的批注文件，但阅读历史的条目里并没有书名这一项，所以永远匹配不上，结果必然是 0。

现已改为直接读取 KOReader 统计库中每本书已记录的标注数与笔记数，与 KOReader 自带「阅读统计」的口径一致（「标注」含纯划线，「笔记」为带批注的条目）。若某本书在统计库里尚未同步，会自动回退去读该书的批注文件。

> 提示：长期未打开的书籍，KOReader 统计库可能还未同步其批注数，数字会偏小，打开一次该书即会更新。

### 4. Top 5 只显示 4 本

书单可用高度不足时，之前会直接砍掉排不下的行——即使只有一行放不下，第 5 本也会整行消失（该书的阅读时长是正常的）。

现改为：空间不足时自动压缩行高（设下限，不会压到看不清）以容纳所选行数，不再因为差一点高度就少一行。壁纸与全屏统计面板均已调整。

### 5. 热力图标题空白

热力图模式下的标题在语言包里缺少对应词条，取到的翻译为空字符串，导致标题区域空白。已补上简体中文、繁體中文（香港）、English 三个语言包的词条。

# v3.9.0

### 新功能

- **标注 / 笔记统计**：书单列表新增「标注」「笔记」两列，分别统计每本书的高亮总数与带笔记的高亮数。数据从各书 DocSettings 的 `highlight` 设置读取，按书名缓存避免重复计算。

- **翻译词条**：新增 `col_anno`（标注 / Marks / 標註）和 `col_note`（笔记 / Notes / 筆記），覆盖简体中文、繁体中文（香港）、英文三语。

### 改进

- **字体对象缓存**：新增 `_font_cache` 表，按 `字体名@字号` 缓存 Font 对象，避免重复加载内置 24MB 汇文明朝体，显著提升渲染速度。

- **drawBoxText 增强**：新增 `fg`（前景色）和 `bg`（背景色）参数，默认黑底白字，支持自定义颜色。

- **轻量模式字号动态缩放**：引入轻量系数 `lmf = 0.72`，在低内存模式下同步下调各档字号下限，避免低分辨率下文字相对过大导致元素重叠。

- **列布局动态计算**：列起点与宽度改为基于实际字号动态计算（含 `col_gap`、`num_col_w` 等），替代原来的固定像素间距。

### 变更

- **书单列表列头**：由「数量 / 单位」（显示 `1` / `本`）改为「标注 / 笔记」（显示实际数字）。

- **版本号**：`_meta.lua` 版本由 `3.9.0` → `3.9.0beta1`；`main.lua` 内部 `PLUGIN_VERSION` 由 `3.9.0beta1` → `3.9.1`。

### 移除 / 禁用

- **低内存模式菜单入口**：菜单项被注释关闭（设置项 `low_memory_mode` 及底层逻辑保留，如需恢复取消注释即可）。
