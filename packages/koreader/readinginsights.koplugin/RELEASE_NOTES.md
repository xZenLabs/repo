# v6.13.0

## Book info popup

A new compact popup about the book you are reading, showing its cover, title, author and series.

Open it from Tools > Reading insights > Show Book info, with the new gesture/dispatcher action, or by tapping the "This book" header in the Book progress popup.

Settings > Book info lets you change the cover (on/off, size, rounded corners, shadow, border), show or hide the author and series, and set the fonts.
