# v1.3.0 · 2026-11-22

- KOReader actions can now run more than one action at once. When you pick a KOReader action, check as many as you like, then use **Arrange actions** to set the order they run in.
- Each action now has a **Keep menu open** option, so the menu can stay up while you adjust things like the frontlight.
- Long-pressing a menu item now opens a new edit sheet. It shows the item's main and second actions, its icon and its options, and lets you move the item, all in one place.
- You can set how narrow menus are allowed to get in **Tools > MiniMenu > Appearance > Minimum width**.
- **New menu...** now creates an empty menu instead of filling it with the default items.
- Deleting an item now asks you to confirm first.
- Fixes and polish:
  - The d-pad can now reach the second action of a grayed-out row.
  - Nested edit sheets have better contrast.
  - The editor shows items without a main action as "No action" and grays them out.
  - Checkmarks line up properly again.

**Full changelog**: https://github.com/vishnumad/minimenu.koplugin/compare/v1.2.0...v1.3.0

# v1.2.0 · 2026-11-07

- MiniMenu now supports secondary actions. Long-press on a menu item and add a secondary action by pressing **Add second action...**
- The edit dialog got a small redesign to accommodate the new options.
- Icon sizes for menu items can be changed independently of font size in **Tools > MiniMenu > Appearance > Icon size**

**Full changelog**: https://github.com/vishnumad/minimenu.koplugin/compare/v1.1.0...v1.2.0
