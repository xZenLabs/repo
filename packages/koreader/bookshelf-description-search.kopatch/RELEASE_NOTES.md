# v1.0.0 · 2026-11-21

First release. Finds a book's description on Apple Books and Google Books and saves it as KOReader's custom description, from a Blurb tab in Bookshelf or from the file browser's long-press menu.

Install: copy 2-bookshelf-description-search.lua (below) into koreader/patches/ and restart KOReader. See the README for details.
