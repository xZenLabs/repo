# v1.2.5 · 2026-11-04

## Fixes

- Added a compatibility fallback when KOReader skips or disables startup user patches.
- Added **Tools → Macintosh 1984 → Theme diagnostics**.
- Runtime failures are now recorded and displayed instead of leaving the plugin silently unthemed.
- Preserved the one-time restart prompt for fresh installations and Storefront updates.

## Install

Download `mac1984-koreader-v1.2.5.koplugin.zip`, or update through Storefront.
